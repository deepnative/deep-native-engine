# Shared repository instructions

Read and follow [AGENTS.md](AGENTS.md) before work; it is the common working agreement for Claude Code, Codex and teammates. Follow [issue coordination](assets/docs/workflows/ISSUE-COORDINATION.md) and [the team workflow](assets/docs/workflows/TEAM-WORKFLOW.md).

Use an isolated Git worktree with a `codex/` branch for every new implementation or repository edit. Identify your actual worker/tool, unique claim ID, owned files/scope, branch and worktree path even when sharing a GitHub account. Preserve competing claims and serialize the shared full local gate. The common agreement governs authorization, BDD, verification, merge, demo and safe cleanup; this entry point adds no permissions or exceptions.
