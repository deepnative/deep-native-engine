06 / GOOD TO KNOW

A few useful
answers.

Still wondering about the preview? Write to DN Team.

Do I need to know how to code?+

No. The first learning experience is made for beginners and uses everyday, invented examples. Technical paths are optional.

Can I use the app online right now?+

The current application is a local preview. You can run it on your own computer by following the repository setup guide. This website introduces the product; it does not host member accounts.

Is there a live AI tutor or formal assessment?+

No. The preview uses sample content and deterministic exercises. It does not connect to a live AI provider or offer qualified assessment.

What does it cost?+

Foundation access and pricing have not been decided. The local preview has no payment flow, and no coaching package is required to explore the learning experience.
