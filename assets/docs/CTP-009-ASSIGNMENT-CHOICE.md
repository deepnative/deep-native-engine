# CTP-009: private published-assignment choice slice

**Issue:** [CTP-009 #33](https://github.com/deepnative/deep-native-engine/issues/33)
**Prepared:** 23 September 2026
**State:** local synthetic preview; bounded delivery slice

A member can choose an exact published sample assignment from the learning path and see the saved choice after reload. The library's readable sample text and the existing local foundation lesson remain available to general, non-IT professional and IT learners without a coding, employer or paid-plan prerequisite. The choice is a next practice action, not a completion, credential, assessment or expert booking.

The option list contains only the latest published version of each assignment. It matches the current goal, primary or additional background, selected domains of interest and a minimum **self-reported** AI-experience level. Experience is guidance, never verified skill. A prerequisite is eligible only when empty, `None`, or exactly `LOCAL-FIRST-EXERCISE-COMPLETE` with an observed self-assessed completion of the current local foundation exercise. Any other free-text prerequisite remains unavailable; the application does not guess that it has been met. The editor may set minimum experience and the documented prerequisite when creating a synthetic draft. The twelve PLAN-004 files remain sign-off-blocked drafts and cannot enter this option list.

Migration `010-assignment-choice.sql` adds the bounded experience field to catalog versions and a private member-owned `(content ID, version)` choice. Its foreign keys cascade on member deletion. The selection write rechecks that the exact version is still the latest published assignment, so retirement or a newer release cannot turn a stale form into a current choice. On every dashboard read, the choice is compared with the current eligible list; after a goal/interest change, version replacement or retirement, only an unavailable-state message appears. The old title is not disclosed in that state, and previous local exercise progress remains intact. Invalid or forged choices get a recoverable error; the shared Origin and CSRF checks still apply.

Verification maps browser journeys L32–L34 to an exploratory general learner, a professional whose observed local exercise satisfies the named prerequisite, and an IT learner whose self-report changes eligibility before retirement. Unit cases cover match and conservative failure paths; real PostgreSQL cases cover publication state, version replacement, privacy, retirement and deletion. The complete `make verify` gate, pre-push hook, PR CI and resulting main CI are required on their exact revisions. The separate full-MVP register remains outstanding.

This slice does not deliver the qualified six-lesson foundation, a transcript reviewed for accessibility, structured multi-item prerequisites, an editor UI for all audience tags, assignment submission/revision or formal progress, production identity, qualified assessment, or the member-to-reviewer journey. Those unmet #33 acceptance areas require linked follow-ups before Done closeout under the current team workflow. Rollback is to stop using the choice UI after preserving or deliberately clearing local synthetic choices; do not casually drop a populated member table or catalog field. No deployment or commercial launch is implied.
