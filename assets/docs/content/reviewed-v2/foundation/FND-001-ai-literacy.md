# What AI can help with

**Goal:** choose a small task where AI can offer a draft and identify what a person still needs to check. **Suggested time:** 12–15 minutes.

Generative AI tools can draft text, summaries, plans and suggestions from the information and instructions they receive. A fluent answer can still omit a constraint, invent a detail or reflect an unsuitable assumption. Treat an output as a draft to examine, especially when it affects someone else. You remain responsible for deciding whether to use it. The practice below can be completed on paper without an AI account or a provider call.

Start with a task you understand. Name the desired result and the information you have permission to use. Decide what would make the result useful and what would make it unsafe or misleading. If you cannot check the result or if the task needs a qualified decision, ask a person with the right responsibility rather than relying on a generated answer.

## Practice with invented information

Choose one route. Write a two-sentence task for a hypothetical AI assistant, then answer the three checks below. You do not need to run the prompt.

- **Exploratory:** A neighbourhood group has 12 volunteers and two hours on Saturday. Ask for an event plan that allocates roles without inventing a venue or budget.
- **Non-IT professional:** An imaginary team has three possible meeting topics and 30 minutes. Ask for a draft agenda, marking any missing owner or decision as unknown.
- **IT practitioner:** A sample sign-up page has email and password fields. Ask for a high-level test checklist that includes invalid input and account-enumeration privacy; no code is needed.

Checks: (1) Which supplied facts must appear? (2) Which detail must remain unknown? (3) Who can verify the result before use? A useful self-check answer names the two-hour and 12-person limits, the missing venue/budget, or the test page's privacy condition, depending on the route. “The AI said so” is never the verification plan.

**Reflection:** Choose one output you would accept as a starting draft and one claim you would hold for human checking. Record a question for the next lesson. Completing this practice is self-reported learning, not a formal assessment.
