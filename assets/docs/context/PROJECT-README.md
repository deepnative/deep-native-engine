# Deep Native Engine: AI learning and participation ecosystem

[Master roadmap](https://github.com/deepnative/deep-native-engine/issues/1) · [Product direction](https://github.com/deepnative/deep-native-engine/blob/main/assets/docs/PRODUCT-DIRECTION.md) · [Milestones](https://github.com/deepnative/deep-native-engine/milestones)

For IT practitioners, professionals in other fields, students/career changers, creators/entrepreneurs and curious learners who want to understand, apply and contribute to the future of AI. Backgrounds and goals may overlap; coding, a job title, a client or contractor status are not common-admission prerequisites.

**Core experience:** accessible AI foundations → goal-appropriate practice/projects → private progress and useful feedback → opt-in learning circles and reviewed contributions. Career/contractor paths and high-touch coaching are optional. Non-IT learners and bounded participation are in the private MVP, not deferred expansions.

Phase and Roadmap priority fields complement the native parent/sub-issue hierarchy. GitHub is the operating backlog; source snapshots retain historical provenance.

Dates remain estimates.
