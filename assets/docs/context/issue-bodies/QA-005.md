- [ ] Core member/coach/operator journeys work at mobile and desktop widths, keyboard-only navigation, readable labels/focus/errors and page-reload recovery.
- [ ] Run the approved Chromium/Firefox/WebKit matrix with deterministic data; automate meaningful accessibility checks and perform manual keyboard/focus review.

## Verification and acceptance evidence

Browser matrix reports/traces, keyboard/accessibility review and measured workload results compared with approved budgets.

E2E coverage means distinct passing scenario IDs divided by all approved IDs, not test count or pass percentage. Missing/skipped/quarantined/failed cases do not count.
