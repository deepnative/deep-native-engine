# CTP-008 private catalog next lesson

Issue #298 adds an optional next-lesson suggestion to the private `/learn` plan. The existing timed first-week starter remains based on the 12-minute local lesson. Catalog lessons have no reviewed duration, so the suggestion sits outside that time budget and never claims an appointment, qualified curriculum, assessment, payment or live service.

The dashboard reads current published catalog versions and the session member's own exercise and exact-version lesson activity. It applies the same goal, background/interest, domain, self-reported experience and recursive prerequisite checks used for synthetic assignment choices. Only curated, published, non-signoff-required lessons qualify. A started unfinished lesson is preferred; otherwise, a narrower matching goal/background/domain tag set ranks ahead of a broad sample. Self-assessed lessons are no longer suggested. No match produces an honest empty state. A member may still browse the existing local library, and another member's activity cannot change this suggestion. Goal changes and content replacement/retirement recalculate the current suggestion without changing historical activity.

There is no new table or provider. The feature is read-only over existing private member and synthetic catalog data. Rollback is to remove the suggestion from `/learn` and retain the underlying catalog and versioned progress; do not erase member activity. Qualified six-lesson content and reviewed alternatives remain under #93/#97/#117. Foundation access and paid coaching terms remain under #95. Passing local verification does not establish those decisions or full-MVP acceptance.
