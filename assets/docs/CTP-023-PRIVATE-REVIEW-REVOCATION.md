# Private-review evidence consent revocation

This bounded local-preview change lets an authenticated member revoke the `private-review` scope on evidence they own. The CSRF-protected `POST /api/evidence/:id/revoke-private-review` endpoint returns 204 only when active consent changes; unauthenticated, staff, other-member, invalid and repeated requests receive 403 without changing the object. A file may remain privately stored with no active sharing scope. Revocation does not delete the file or alter its separately recorded community-publication or circle consent.

Migration 023 replaces the upload-era database check requiring at least one *current* sharing scope with a constraint that also permits an object carrying a private-review revocation timestamp. Upload still requires explicit rights and at least one initial scope. The transition clears `private_review_allowed`, records the revocation time and changes a queued submission to `withdrawn` in one PostgreSQL statement. Existing reviewer grants remain as historical records, but every download request rechecks current object consent and submission state; previously issued short-lived reviewer links and new link requests are denied after the transition. Owners retain private download access. A reviewed submission keeps its historical status while current review access stops.

Roll back application code only together with a compatible database migration plan. Restoring the old at-least-one-scope constraint is unsafe while private retained objects with zero sharing scopes exist. A rollback must first preserve or remove those rows under an owner-approved retention decision; it must never silently re-enable consent. The safe operational fallback is to disable reviewer access and keep the new schema until a reviewed forward fix is available.

The current preview also exposes this action in the member-owned `/evidence` page. Members can add an invented text sample with explicit rights and private-review consent, inspect pending or clean safety state, download only a clean sample, revoke private-review access, and delete the sample after confirmation. The page does not offer re-consent, a qualified reviewer process, live scanner, community publication, hosted retention policy or full-MVP acceptance. F-BUILD-08-B remains provisional browser evidence (`approved:false`).
