# CTP-009: synthetic lesson reader and observed activity

**Issue:** [CTP-009 #102](https://github.com/deepnative/deep-native-engine/issues/102)
**Scope:** bounded local preview using invented, published synthetic lessons.

The learning library shows readable text for a published sample lesson. A member opening its reader records an `opened` event for the exact content ID and version. The member must separately choose **Start this lesson** and then confirm **Mark self-assessed complete**. These states mean page access, an explicit start action, and a member's own completion report. They do not establish reading comprehension, skill, formal review, employment, earnings or curriculum approval. No PLAN-004 foundation draft is released by this change.

`lesson_activity` is keyed by member, content ID and version. The authenticated browser session supplies the member ID; callers cannot choose another member. Opening and state changes recheck that the version is the current published lesson. A newer published version or retirement stops further actions on the old version, while the private history remains visible with an unavailable label. Changing goals does not rewrite that history. Deleting the preview cascades its activity rows. The existing same-origin and CSRF checks apply to progress forms; invalid or stale actions do not claim a save, and a database error reports an unconfirmed outcome that the member can inspect after recovery.

Verification is in local scenario register `initial-learning-v16`: L42 covers readable text, keyboard actions, reload and goal change for an exploratory learner; L43 covers separate professional/IT sessions, stale writes, replacement and retirement. Both run at desktop and mobile Chromium widths. Unit checks cover view labels, route failure states and bound SQL parameters; real PostgreSQL checks cover publication, member isolation, version transitions and deletion. The complete `make verify`, exact clean commit gate, pre-push hook, PR CI and resulting main CI provide delivery evidence.

Rollback: stop exposing the reader actions after preserving existing private activity; do not drop a populated `lesson_activity` table. Its rows are removed when the member deletes the preview. The current application still lacks reviewed six-lesson content and transcripts, a qualified reviewer decision, assignment-linked observed progress and release-level assistive technology/browser evidence. Those require [the reviewed-reader follow-up #117](https://github.com/deepnative/deep-native-engine/issues/117), its dependencies #93, #97, #103 and #104, and QA-005 #109. This local synthetic slice does not authorize deployment or formal assessment.
