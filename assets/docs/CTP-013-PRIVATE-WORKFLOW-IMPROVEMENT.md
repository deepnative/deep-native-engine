# Private workflow improvement proposals

This local preview lets a member suggest an original improvement to one exact version of a file-backed synthetic workflow. The link from a workflow detail page opens the existing private proposal form with a workflow reference. The server checks that the reference names the current supported version when the draft is saved and again before private moderation submission. If the workflow changes, an old draft remains owner-readable and withdrawable, but cannot be newly submitted as a current-version proposal.

The optional workflow ID and version are stored with the member-owned proposal in PostgreSQL. Existing member and moderator authorization, CSRF checks, sample and private-rights attestations, queue states and bounded owner export apply. Withdrawal or moderator rejection redacts the proposal text, rights notes and workflow reference. Account deletion cascades the row. An unrelated member and a reviewer without the moderator role cannot read the private proposal or queue. The public workflow listing, detail and download do not read proposal data.

This is a private synthetic suggestion, not a contribution license, qualified review, approved instruction or publication. The existing moderator can quarantine or reject it, but cannot approve or publish it. Reuse terms, sharing scope, qualified reviewer identity and any public publication remain blocked on #97, #114 and #115. A database or file-read failure returns an unconfirmed result and must not be interpreted as a save or submission.

Migration 034 adds nullable, paired workflow-reference columns. It does not rewrite existing generic proposals, and older app versions can ignore the optional columns for a rollback. Reversing the feature removes the new form link and reference handling; retain or delete the added reference columns only through a separately reviewed data migration. For local disposable test data, member deletion already cascades the proposal rows. This note does not assert hosted backup erasure or production retention terms.
