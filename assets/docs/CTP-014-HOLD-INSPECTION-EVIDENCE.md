## Review and limits

Author design/self-review targets the SQL lock order, exact authority/linkage, immutable/audited instructions, source-independent retention, bounded operation deadlines and failure sanitization. Unit ports exercise policy decisions; actual PostgreSQL transactions establish race/erasure behavior; the browser exercises runtime/routes/HTML with invented data. No separate independent review is claimed.

There is no resolve/retry/refund/settlement command or mutation route. Inspection does not prove external execution, add a paid allowance, provide qualified review, operate a staffed service, meet broader full-MVP criteria or deploy anything. No captured gate server/database is used for a concurrent demo. Use [the private operation guide](PRIVATE-LOCAL-AI-HOLD-INSPECTION.md) and the milestone demo procedure for a separately owned preview after verified main delivery.
